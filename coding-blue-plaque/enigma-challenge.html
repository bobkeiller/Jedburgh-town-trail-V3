The Enigma Challenge

Just for fun

This is a simplified version of an Enigma machine. It has three simple rotors and a reflector. Real machines used selectable rotors and a plugboard system that vastly increased the cipher’s complexity.

How it works

Each wheel is internally wired so that an input letter emerges as a different output. The signal passes through wheels one, two and three, reaches the reflector, then travels back through all three wheels.

If nothing moved, each letter would always produce the same output. But the wheels move. The right-hand wheel rotates one notch whenever a key is pressed. The next wheel advances after every 26 steps of the wheel to its right, and the left wheel advances in the same way. A three-wheel display has 17,576 possible positions.

Imagine sending AAA. It might become XDL. Typing AAA again immediately would give something different because a wheel has moved. A receiving operator sets an identical machine to the agreed starting position and types the coded message to recover the original.

This interactive version demonstrates the reciprocal cipher and rotor movement; it deliberately omits much of a real Enigma machine’s mechanical complexity.
